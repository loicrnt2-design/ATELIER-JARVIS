          Réglages

          Thème

          Intelligence artificielle (optionnelle)

          Compatible avec les API de type « chat/completions » (OpenAI, serveur local Ollama sur http://localhost:11434/v1, etc.). Une fois activée, vos messages de conversation sont envoyés au fournisseur indiqué. Ni l'agenda ni les tâches ne sont transmis. La clé est conservée en clair dans ce navigateur : ne l'utilisez pas sur un poste partagé. Certains fournisseurs bloquent les appels directs depuis un navigateur (CORS).

          Voix

          Sous Chrome et Edge, l'audio dicté est traité par le service en ligne du navigateur. Le micro n'est activé que lorsque vous cliquez sur le bouton central.
